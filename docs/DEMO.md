# Демонстрация проекта преподавателю

## Сценарий на 3–5 минут

1. Подключить NodeMCU к USB-питанию. Показать сеть `Baikal_Conference` в списке Wi‑Fi телефона.
2. Подключить телефон (пароль `Baikal2026`). Показать локальный сайт по адресу `http://192.168.4.254`, расписание и сведения о месте проведения.
3. Зарегистрировать тестового участника. Показать автоматически назначенный номер места.
4. Открыть `http://192.168.4.254/admin`, войти как `admin` / `Baikal2026!` и показать заявку в списке.
5. Изменить дату или программу, сохранить, обновить главную страницу. При необходимости изменить место участника и скачать CSV.
6. Объяснить, что интернет отключён: ESP8266 создаёт локальную сеть и отвечает на DNS-запросы, а ноутбук обслуживает сайт и SQLite.

## Проверяемые случаи

| Действие | Ожидаемый результат |
| --- | --- |
| Повторная заявка с той же почтой | Дубликат не создаётся, отображается уже назначенное место |
| Регистрация двух участников | Им выдаются разные свободные места |
| Попытка назначить занятое место | Админка показывает ошибку, оба назначения сохраняются |
| Вместимость меньше числа участников | Настройка отклоняется |
| Перезапуск сайта | Заявки и программа остаются в SQLite |
| Открытие админки без входа | Перенаправление на страницу входа |

Автоматическое всплывающее окно captive portal зависит от ОС телефона. Для гарантированной демонстрации используется локальный HTTP-адрес.
